# Сайт «Моя карьера» — Новосибирская область

Одностраничный адаптивный сайт по ТЗ v1.0 от 04.11.2026: лендинг, две формы заявок, серверный обработчик, защищённый реестр заявок, юридические страницы.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Лендинг: шапка, первый экран, «Кому полезен проект», форматы, координатор, мероприятия, шаги, формы, FAQ, подвал |
| `privacy.html`, `consent.html`, `cookies.html` | Политика, отдельный текст согласия, уведомление о cookie (**проекты — проверить юристом**). Короткие адреса `/privacy`, `/consent`, `/cookies` настроены в `.htaccess` |
| `send.php` | Приём заявок: CSRF, honeypot, проверка времени заполнения, лимит частоты с IP, валидация, запись в SQLite, уведомление на почту, опционально Битрикс24 |
| `admin.php` | Реестр заявок: фильтры, карточка, статусы, ответственный, журнал изменений, выгрузка CSV |
| `lib.php` | Общие функции, схема БД |
| `config.sample.php` | Шаблон настроек → скопировать в `config.php` |
| `assets/js/config.js` | Настройки фронтенда: ID Яндекс Метрики, версия согласия |
| `assets/` | Стили, скрипты, шрифт Inter (OFL, локально), иллюстрация, OG-картинка |
| `robots.txt`, `sitemap.xml`, `favicon.svg` | SEO (домен `example.ru` заменить) |

## Требования

PHP 8.1+ с `pdo_sqlite`, `mbstring`, `session` (и `curl` для Битрикс24). Apache с `mod_rewrite`/`mod_headers` или nginx. Хостинг и база — на территории РФ (152-ФЗ, ст. 18). HTTPS обязателен.

## Установка

1. Загрузить файлы на хостинг.
2. `cp config.sample.php config.php`, заполнить: `ip_salt`, `allowed_origins`, `notify_emails`, пользователей реестра:
   `php -r "echo password_hash('пароль', PASSWORD_DEFAULT), PHP_EOL;"`
3. Желательно вынести базу за пределы публичной папки (`db_path`). Папка `data/` закрыта `.htaccess`.
4. Заменить `example.ru` в `index.html`, `robots.txt`, `sitemap.xml`.
5. Яндекс Метрика: указать ID в `assets/js/config.js` (`metrikaId`). Счётчик грузится только после согласия посетителя на аналитические cookie.

nginx — закрыть служебные файлы и задать короткие адреса:
```nginx
location ~ ^/(config|config\.sample|lib)\.php$ { deny all; }
location ~ ^/(data/|README\.md) { deny all; }
location ~ ^/(privacy|consent|cookies)/?$ { try_files /$1.html =404; }
```

## Аналитика

События (в `dataLayer` и цели Метрики): `participant_form_view`, `participant_form_submit`, `employer_form_view`, `employer_form_submit`, `contact_click`, `official_link_click`.

## Заявки

Поля в БД: номер (`MK-2026-000001`), тип, ФИО/компания/контактное лицо, телефон (`+7XXXXXXXXXX`), e-mail, категория, интерес, комментарий, подтверждение 18+, дата/время и версия согласия, UTM (source/medium/campaign/content/term), URL страницы, статус, ответственный, журнал изменений.
Статусы: Новая → В работе → Связались → Подтверждено участие/сотрудничество → Закрыта / Отказ.
Политические предпочтения не собираются. Самостоятельные заявки участников — только 18+.

Битрикс24 выключен (`bitrix24.enabled = false`). Включать только после оформления отношений оператора/обработчика ПД; вебхук хранится только в `config.php`.

## Проверка (выполнено при сборке)

- Каждая форма с тестовыми данными создаёт одну заявку нужного типа; UTM, URL, версия согласия сохраняются
- Кнопка отправки неактивна до отметки обязательных согласий; чекбоксы по умолчанию не отмечены
- Неверный телефон подсвечивается, сервер возвращает понятное сообщение об ошибке
- Ширина 320 / 375 / 1440 px — без горизонтальной прокрутки
- Реестр: вход, смена статуса и ответственного, запись в журнал

Если открыть `index.html` как файл без сервера, формы работают в демо-режиме (данные никуда не отправляются).
